# Argyle Docs

> Argyle documentation for integrating real-time income, employment, payroll document, and banking data into verification workflows. Use this index to find the right guide, Link page, API reference, integration guide, or OpenAPI specification.

Important context:
- Payroll VOIE uses connected payroll account data for income and employment verification.
- Doc VOI uses uploaded payroll and identity documents, with OCR and authenticity support where available.
- Banking VOI and VOA use bank-authenticated data for income and asset workflows.
- Link is the user-facing account connection experience. Banking connection flows use session URLs with the banking SDK or an enabled hosted experience.
- Use Sandbox for testing sample users and simulated flows before using Production.
- Prefer the `.md` page links in these indexes for page content; use OpenAPI YAML for generated endpoint schemas.

Common integration flows:
- Payroll flow: create a user, launch Link with a user token or session, listen for account and data webhooks, then retrieve identities, paystubs, payroll documents, or reports.
- Verification flow: order a verification, create a session for the user, monitor verification webhooks, then retrieve the verification result.
- Banking flow: create a Connect URL, complete bank authentication, retrieve bank accounts, then generate banking reports.
